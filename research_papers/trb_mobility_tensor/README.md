# TRB paper: A Typed Multi-Axis Mobility Tensor for Integrated Activity-Tour Choice and Congested Network Assignment

TRB Annual Meeting-style manuscript (U.S. letter, 1-inch margins,
10-pt Times-compatible, single column, pagewise line numbers,
structured abstract, author-date citations).

- `main.tex` / `main.pdf` — the manuscript
- `references.bib` — author-date bibliography
- `figures/` — Figure 1 is the repository architecture figure
  (`figures/framework_2.png`); Figures 2–5 are generated by the paper
  case script

## Every number comes from one script

```bash
python cases/run_mobility_tensor_paper.py --full
```

regenerates the scenario table, the 500-move pricing experiment, the
remainder-decay measurement, the certified scalability ladder,
Figures 2–5, and `certificates.json` under
`cases/outputs/mobility_tensor_paper/`. Copy the refreshed figures here
before rebuilding the PDF. The joint gradient / Hessian / pricing
calculus is unit-tested in `tests/test_quadratic_pricing.py` and
`tests/test_landuse_activity_dta_integration.py`.

## Build

```bash
./build.sh   # pdflatex + biber
```
